How a migration runs

Four steps, every time — nothing is written to the target database until you say so.

  1. 01

    Read the source

    Pulls every row from the old MySQL customers table with pandas.

  2. 02

    Normalize & compare

    Cleans up names, phones and emails, then scores every pair with fuzzy matching.

  3. 03

    Cluster

    Scikit-learn's DBSCAN groups records into duplicate clusters — not just pairs.

  4. 04

    You decide

    Merge a group into one record, or keep every record — then write to the new DB.
